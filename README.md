# Machine Learning Projects

This repository contains multiple machine learning projects. Each project covers different aspects of machine learning, including predictive modeling, classification, and statistical learning.

## Projects

### 1. Ensemble Techniques - Parkinson's Disease Prediction
- **Description:** This project applies ensemble learning techniques to predict Parkinson's disease based on biomedical voice measurements.
- **Techniques Used:** Random Forest, Gradient Boosting, AdaBoost
- **Libraries:** Pandas, Scikit-learn, Matplotlib, Seaborn

### 2. Mobile Price Prediction
- **Description:** A predictive model for estimating mobile phone prices based on their specifications.
- **Techniques Used:** Logistic Regression, Decision Trees, Random Forest, SVM
- **Libraries:** Pandas, Scikit-learn, Matplotlib

### 3. Personal Loan Modelling
- **Description:** This project focuses on predicting whether a customer is likely to accept a personal loan offer.
- **Techniques Used:** Logistic Regression, Decision Trees, Random Forest
- **Libraries:** Pandas, NumPy, Scikit-learn

### 4. Statistical Learning
- **Description:** This notebook explores key concepts of statistical learning and their applications in predictive modeling.
- **Topics Covered:** Regression, Classification, Bayesian Statistics
- **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib
